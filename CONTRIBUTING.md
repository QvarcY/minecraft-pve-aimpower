# Contributing

Thanks for helping improve Minecraft PvE AimPower.

## Development

Requirements:

- Java 25
- Minecraft 26.2
- Fabric Loader 0.19.5+
- Fabric API for Minecraft 26.2

Build with:

    .\gradlew.bat build

## Scope

PvE AimPower is intentionally PvE focused.

Pull requests that introduce player targeting or automatic attacks are outside the intended project scope.

Please keep changes focused, documented and testable.
